# 💱 Conversor de Moedas em Java

Projeto desenvolvido, com o objetivo de praticar **Java**, consumo de **API**, requisições HTTP e organização de código no backend.

Aqui você pode converter moedas de forma simples, rápida e direto pelo terminal 🚀

---

## 🧠 O que foi aprendido neste projeto

✔ Consumo de API de câmbio em tempo real  
✔ Criação de requisições com `HttpRequest`  
✔ Uso do `HttpClient` para chamadas HTTP  
✔ Manipulação de respostas JSON  
✔ Integração da biblioteca **Gson**  
✔ Boas práticas de organização de código  
✔ Estruturação de um projeto Java no IntelliJ  

---

## ⚙️ Funcionalidades

🔹 Conversão entre diferentes moedas  
🔹 Menu interativo no terminal  
🔹 Conversões com valores atualizados pela API  
🔹 Tratamento de erros básicos  
🔹 Encerramento seguro da aplicação  

### 💰 Moedas disponíveis (exemplo)
- Real (BRL)
- Dólar (USD)
- Euro (EUR)
- Peso Argentino (ARS)

✔ Handling JSON responses  
✔ Integration of the **Gson** library  
✔ Best practices for code organization  
✔ Structuring a Java project in IntelliJ  

---

## ⚙️ Features

🔹 Conversion between different currencies
